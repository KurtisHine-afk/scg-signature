# Spartan Capital Group Email Signature Creator

New team members answer a few questions and get a branded HTML email signature to copy into Outlook, Gmail, or Apple Mail.

Live page: https://kurtishine-afk.github.io/scg-signature/

The logo files in `assets/` must keep their exact file names and stay in place. Signatures that have already been sent link to those URLs, so renaming or moving a logo breaks it in existing emails.
